# 📊 Dados do Projeto

O dataset utilizado neste projeto é o **Bank Customer Churn Dataset**, contendo 10.000 registros e 14 atributos sobre o perfil e comportamento financeiro de correntistas bancários.

* **Fonte Original:** [Kaggle - Bank Customer Churn Prediction](https://www.kaggle.com/datasets/saurabhbadole/bank-customer-churn-prediction-dataset)
* **Formato:** CSV (`churn.csv`)
* **Uso no Pipeline:** Os notebooks realizam a leitura direta do conjunto via URL pública, dispensando o download manual prévio para execução.
